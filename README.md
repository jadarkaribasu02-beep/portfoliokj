# Karibasu Jadar Portfolio

A sleek, responsive personal portfolio website for Karibasu Jadar, showcasing software development skills, projects, education, and contact details.

## Overview

This project is a static portfolio built with HTML, CSS, and JavaScript. It includes:

- Animated hero section and loading preloader
- Dark/light theme toggle
- Responsive navigation for desktop and mobile
- About, skills, projects, education, and contact sections
- Social links and resume access button
- Modern cyber-inspired visual design

## Project Structure

```text
.
├── index.html
├── styles.css
├── script.js
├── assets/
│   ├── favicon.svg
│   └── hero-photo.png
└── README.md
```

## Customization

You can easily customize the portfolio by editing:

- `index.html` for content, text, links, and sections
- `styles.css` for colors, layout, spacing, and design
- `script.js` for animations, theme behavior, and interactions
- `assets/` for images, icon assets, and branding

## Deployment

This portfolio can be deployed as a static site on:

- GitHub Pages
- Vercel


## Notes

- The site uses Google Fonts and Font Awesome / Boxicons from CDN.
- Internet access is needed for those external resources to load correctly.
- The resume button is wired to open the resume section or related action in the page logic.
